# Scouting uncertainty v1

True field-level potential remains in the career state for development simulation, but manager
draft decisions receive only team-specific scouting estimates. Each ability estimate uses
addressed deterministic noise, so paired experiments remain reproducible while different teams
can disagree about the same prospect.

Repeated exposure reduces the bounded error range and increases confidence without guaranteeing
perfect information. Reports identify the manager, team, prospect, exposure count, uncertainty,
confidence, and estimated potential, and are included in the Shadow draft audit.

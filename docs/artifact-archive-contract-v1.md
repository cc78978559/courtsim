# CourtSim 产物归档契约 v1

## 目标

在不删除源文件的前提下，将明确选择的本地模拟产物打包为可验证 ZIP。
归档不是清理授权，也不是异盘灾难恢复保证。

## 计划契约

计划文件包含：

```text
format_version
kind
root
include
exclude
summary.files
summary.bytes
entries[].path
entries[].bytes
entries[].sha256
```

条目必须按相对路径排序且唯一。根目录使用生成计划时解析出的本机绝对路径，
所以计划精确绑定当前数据位置，不作为跨机器可移植配置。

## 创建顺序

```text
加载并严格验证计划
→ 检查每个源文件仍存在且不是符号链接
→ 核对大小和 SHA-256
→ 在目标目录创建临时 ZIP
→ 写入固定元数据的内嵌 manifest
→ 流式压缩各源文件
→ 重新打开 ZIP
→ 检查 CRC、条目集合和逐文件 SHA-256
→ 原子替换为最终 ZIP
→ 计算最终 ZIP SHA-256
```

源文件在整个流程中只读。任何检查失败都不会产生最终归档。

## 明确不包含

- 不根据修改时间自动选取文件；
- 不推断哪些正式基线可以丢弃；
- 不删除或移动源文件；
- 不覆盖已有 ZIP；
- 不声称同盘 ZIP 是独立灾难恢复备份；
- 不把压缩成功等同于允许清理。

## 独立验证

```powershell
.\tools.ps1 artifacts-verify-archive <archive.zip>
```

独立验证不访问计划中的原始根目录。它严格检查：

1. ZIP 中只有一个 manifest，且不存在重复路径；
2. manifest 字段、版本、计划哈希、summary 和条目结构合法；
3. 条目是排序且唯一的安全相对路径；
4. ZIP 不包含额外条目、目录、符号链接或加密条目；
5. ZIP 声明大小与 manifest 一致；
6. CRC 和逐文件 SHA-256 全部通过。

## 安全恢复

```powershell
.\tools.ps1 artifacts-restore <archive.zip> <new-directory>
```

恢复目录必须不存在。流程为：

```text
完整验证 ZIP
→ 在目标父目录创建临时恢复目录
→ 流式写出每个文件
→ 逐项复核大小和 SHA-256
→ 写入恢复回执
→ 再次确认正式目标不存在
→ 原子改名为正式恢复目录
```

任一步失败都会删除本次临时恢复目录，不会接触已有目录。恢复回执记录归档
SHA-256、文件数和原始字节数，便于后续恢复来源审计。

## 后续 prune 的前置条件

未来若增加清理能力，至少需要：

1. 显式指定归档 ZIP；
2. 重新验证 ZIP 哈希和内嵌 manifest；
3. 先用独立验证确认 ZIP 内容完整；
4. 证明候选源文件与 manifest 路径、大小和哈希完全一致；
5. 输出待删除绝对路径和总字节的 dry-run；
6. 排除当前正式基线、最近实验和未归档失败诊断；
7. 获得独立的明确删除授权。

当前版本刻意停在归档验证，不实现 prune。

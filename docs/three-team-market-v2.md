# Three-team market v2 contract negotiation tree

v2 在现有原子三方交易引擎之上增加合同条件谈判树，不削弱 v1 的工资、合同、阵容、
选秀权所有权、Stepien 与工资帽校验。

当前 `contract-v1` 的可谈判白盒字段只有年薪和剩余年限，因此 v2 完整覆盖这三个条件：

- 接收方允许的最高年薪；
- 接收方要求的最低剩余年限；
- 接收方允许的最高剩余年限。

每个条件必须绑定一个被送往该接收方的球员。根节点包含全部条件；失败节点每条分支只
放松一个失败条件，最多八个条件、默认四轮（可配置一至八轮）。节点记录连续 ID、父节点、
轮次、仍生效的条件、白盒拒绝原因，以及 `accepted / countered / rejected` 状态。

谈判树本身不执行交易。只有 accepted 节点可以进入执行器；执行前会再次验证 offer 路由
签名、当前合同条件，并调用原生 `apply_three_team_trade` 完整重跑所有法律与工资规则。
因此合同在谈判后发生变化、交易路由被替换，或原生合法性状态改变时，成交都会失败，
不会依赖过期的 shadow 结论。

未来若合同 schema 增加保障比例、球队/球员选项、交易保证金或 no-trade consent，应先
升级规范合同账本，再 append-only 扩展条件枚举；v2 不伪造当前账本尚不存在的条款。
